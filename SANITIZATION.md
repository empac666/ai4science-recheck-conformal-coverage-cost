# Public-copy provenance / 公开副本说明

This package follows the R12 public layout with root documentation, preregistration/hash records, scripts and result artifacts. All original R13 artifacts were read-only inputs. Public code and archive adaptations do not alter original judgments.

- PREREG.md, prereg_R13_FROZEN.md and prereg_R13_v1.2.md are byte-identical final preregistrations. Their original freeze SHA-256 remains valid.
- Scientific outputs (rows, predictions, per-task results, independent summaries, branch/paired summaries, object snapshots and combination) retain original bytes. No seed or row was removed. Numeric scientific data remain public anonymous observation/group IDs.
- The 23,764,537-byte task manifest was losslessly compacted below the 20 MB cap: same parsed JSON, same numeric values, same task keys. Historical hashes refer to original formatting.
- Instance hardware, operating-system distribution and threadpool architecture details were removed from environment and smoke records. Scientific software versions, parameters, resource totals and protocol limits remain.
- The execution-lock copy is a historical subset: excluded runtime-input path entries and the old environment-specific launch command were removed. Its file-hash values and original code fingerprint are historical evidence, not assertions that adapted public files have the original bytes. Local integrity is verified against SHA256SUMS and PROVENANCE.json instead. Raw excluded input implementations are unavailable in this package; upstream hashes alone do not authenticate their contents here.
- common.py uses public data/concrete.csv, sourced from the public-data evidence mirror, never from excluded runtime inputs. The supervisor uses a relative logs directory. freeze_execution.py generates a new reproduction lock without collecting instance hardware or requiring excluded source files. The original network preparation script is omitted. scripts/reproduce.py rebuilds manifests in a new output directory and reuses archived input/FRP-reference attestations; this is not a fresh independent upstream FRP implementation check.
- Results and deviations use neutral interval-score terminology and remove process identifiers, internal status-update paths and the first-attempt backup locator. The first-attempt scientific-object existence, unknown pre-relaunch inspection, prohibited clock reset and missing cross-attempt CPU close-out remain fully disclosed. References to excluded first-attempt evidence are disclosures, not bundled verifiable evidence. Raw launch/process logs, review/session logs, environments, personal metadata and first-attempt backups are excluded.
- scripts/verify_R13_readonly.py adapts the original verifier to relative paths and public provenance hashes. It recomputes every archived task, row, summary, paired CI and four scientific objects with the unchanged numerical/judge logic. It does not claim to validate original unavailable private source bytes or whole-round procedural integrity. The original verification JSON is archived evidence; a new verifier report is written only to an explicitly requested external path.

PROVENANCE.json maps each copied artifact to its original relative source, original hash, public hash and transformation classification. Newly authored public documentation and tools are covered by SHA256SUMS. All files are included in that manifest except SHA256SUMS itself: a file cannot contain its own stable cryptographic checksum. PRIVACY_SCAN.txt is included. No original freeze record or judgment was edited.
